# YURI22 × DONA — Fan page 2026

Site responsivo feito com HTML5, CSS3, Bootstrap 5.3 e JavaScript.

## Como publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos mantendo as pastas `assets/css` e `assets/js`.
3. Vá em Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha `main` e `/ (root)` e salve.

## Imagens
O site usa miniaturas públicas de vídeos/clipes hospedadas no YouTube/Kick/Twitch. Como são imagens externas, podem mudar ou sair do ar. Se quiser usar fotos próprias, salve-as em `assets/img` e altere o `src` correspondente no `index.html`.

## Observação
Fan page não oficial. Não representa nem é administrada por Yuri22 ou Dona. A parte biográfica é um resumo de informações públicas; a programação de lives muda. Confira os canais oficiais para saber se estão ao vivo.
